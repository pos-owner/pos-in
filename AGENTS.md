# AGENTS.md

pOS is a React PWA plus a Hono API, deployed as one Cloudflare Worker (static assets + `/api/*`), with D1 for data and photos, a Cron Trigger + Queue for the daily rent cycle, and optional Workers AI. Start with `README.md` and `docs/architecture.md`.

## Key directories

- `src/`: React app. Screens are grouped by role (`auth`, `owner`, `staff`, `tenant`, `shared`, `tools`, `public`). `styles/global.css` imports the design-system partials in cascade order.
- `worker/index.ts`: the Worker entry (fetch, scheduled, queue).
- `worker/server/`: `routes.ts` plus `*Routes.ts` endpoint groups; `core/` holds platform services, `domain/` holds business logic (`daily.ts` is the daily cycle).
- `worker/db/schema.ts`: Drizzle schema, the source of truth for tables.
- `shared/`: code used by both browser and Worker (PDF layouts, login key).
- `drizzle/` → `migrations/`: generated by `npm run db:generate` / `scripts/migrations.mjs`. Never edit by hand.
- `tests/unit`, `tests/api` (Miniflare D1), `tests/helpers`.

## Conventions

- Explicit `.ts` import extensions in Worker, shared and test code; no `enum` or `namespace` (Node type stripping).
- Use `bindings()` and `env("NAME")` from `worker/server/core/bindings.ts`; never pass `env` through domain code.
- D1 has no interactive transactions: use guarded statements, `db.batch`, or triggers.
- Migrations are additive; never edit one that has been deployed.
- API headers live in `core/secure.ts`; static file headers in `public/_headers`. Secrets never go in `wrangler.jsonc`.
- Every imported package must be in `package.json` (`tests/unit/dependencies.test.ts` enforces this).
- Prettier, 120 columns. Hindi strings go in `src/i18n/hi.json`, keyed by English text.
- Dark-mode CSS must cover both `@media (prefers-color-scheme: dark)` with `:root:not([data-theme="light"])` and `:root[data-theme="dark"]`.
